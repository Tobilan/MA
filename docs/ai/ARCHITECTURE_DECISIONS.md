# Architekturentscheidungen

Im derzeitigen Repository-Stand sind keine belastbaren projektspezifischen Architekturentscheidungen zum IFC-Viewer dokumentiert. Deshalb werden hier keine Entscheidungen erfunden. Neue Einträge verwenden die folgende Struktur und eine fortlaufende ID.

## ADR-000: Vorlage für zukünftige Entscheidungen

- **ID:** ADR-000
- **Titel:** Platzhalter – nicht als Projektentscheidung verwenden
- **Status:** Vorlage
- **Kontext:** Welche fachliche oder technische Spannung erfordert eine Entscheidung?
- **Entscheidung:** Welche Option wird gewählt? Dieser Abschnitt bleibt bei der Vorlage leer.
- **Folgen:** Welche positiven und negativen Konsequenzen entstehen?
- **Nachweise:** Welche Quellen, Implementierungspfade, Versuche oder Protokolle tragen die Entscheidung?
- **Ersetzte Entscheidungen:** Keine.

Zulässige Statuswerte in der Dokumentation sind „vorgeschlagen“, „angenommen“, „abgelehnt“ und „ersetzt“. Eine angenommene Entscheidung wird nicht rückwirkend inhaltlich umgeschrieben. Eine Änderung erfordert eine neue ADR, die die frühere Entscheidung ausdrücklich ersetzt und auf sie verweist.
