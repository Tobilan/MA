# Generierte Review-Pakete

`prepare_review.py` legt hier aufgabenspezifische Review-Pakete ab. Die Pakete, Diffs, Rohantworten, normalisierten JSON-Dateien und Ausführungsprotokolle sind flüchtige Artefakte und werden durch die lokale `.gitignore` ausgeschlossen. Diese README und `.gitignore` bleiben versioniert.
