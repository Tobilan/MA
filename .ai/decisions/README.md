# Review-Entscheidungen

Entscheidungsprotokolle werden nach dem Muster `YYYY-MM-DD-<task-name>-review-decisions.md` benannt und versioniert. Für jedes Finding ist genau einer der Statuswerte `ACCEPTED`, `REJECTED` oder `DEFERRED` mit deutscher Begründung festzuhalten. Als Ausgangspunkt dient `DECISION_TEMPLATE.md`.
