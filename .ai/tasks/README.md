# Aufgabendateien

Für jede zusammenhängende Änderung wird aus `TASK_TEMPLATE.md` eine eigene, möglichst vor Beginn versionierte Aufgabendatei erstellt. Sie begrenzt den Arbeitsumfang, legt den menschlich bestimmten Commit-Modus fest und benennt die zu prüfenden Behauptungen und Nachweise. Externe Implementierungsevidenz wird aus `EXTERNAL_EVIDENCE_TEMPLATE.json` als strukturiertes Manifest erfasst; das Template ist vor Verwendung vollständig zu konkretisieren.
